# sample_data/

Entirely synthetic fixtures used for tests, the Phase 1 Gemma spike, and the
in-app "Use Synthetic Demo Session" mode. No real patient data is stored here
or anywhere else in this repository.

- `synthetic_patient.json` — the single synthetic patient (`SYN-001`, "Ms.
  Lin") described in SPEC.md section 5.
- `synthetic_metrics.json` — synthetic movement metrics matching the shape
  Phase 3's movement analysis will produce, used to demo/test report
  generation before the camera pipeline exists.
